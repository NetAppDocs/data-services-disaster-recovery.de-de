= Replizieren Sie Anwendungen an einen anderen Standort mit NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
Mit NetApp Disaster Recovery können VMware-Anwendungen vom Quellstandort mithilfe der SnapMirror Replizierung an einen entfernten Notfallwiederherstellungsstandort in der Cloud repliziert werden. Die Aktualität der Wiederherstellungsdaten an einem entfernten Standort stellt sicher, dass geschützte Anwendungen aus aktuellen SnapMirror Snapshots wiederhergestellt werden können.


TIP: Nachdem Sie den Disaster Recovery-Plan erstellt, die Wiederholung im Assistenten festgelegt und eine Replikation an einen Disaster Recovery-Standort initiiert haben, überprüft Disaster Recovery alle 30 Minuten, ob die Replikation tatsächlich gemäß dem Plan erfolgt. Sie können den Fortschritt auf der Job Monitor-Seite verfolgen.

*Erforderliche NetApp Console-Rolle* Für die Ausführung dieser Aufgabe ist die Rolle „Superadmin“, „Disaster recovery admin“ oder „Disaster recovery failover admin“ erforderlich. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Erfahren Sie mehr über Benutzerrollen und Berechtigungen in NetApp Disaster Recovery"^]. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

.Bevor Sie beginnen
Bevor die Replikation initiiert wird, sollte ein Replikationsplan erstellt und für die Replikation konfiguriert werden. Dann erscheint die Option *Replicate* im Menü „Aktionen“.

.Schritte
. Melden Sie sich an bei https://console.netapp.com/["NetApp Console"^] .
. Wählen Sie in der linken Navigation der NetApp Console *Schutz* > *Notfallwiederherstellung*.
. Wählen Sie im Menü *Replikationspläne* aus.
. Wählen Sie den Replikationsplan aus.
. Rechts das Menü *Aktionen* image:../use/icon-horizontal-dots.png["Aktionsmenüsymbol im Disaster Recovery Service"] auswählen und anschließend *Replizieren* wählen.
