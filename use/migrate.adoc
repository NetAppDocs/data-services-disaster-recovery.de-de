= Migrieren Sie Anwendungen mit NetApp Disaster Recovery an einen anderen Standort
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
Mit NetApp Disaster Recovery können Sie VMware-Apps von Ihrem Quellstandort auf einen anderen Standort migrieren.


TIP: Nachdem der Replikationsplan erstellt, die Wiederholung im Assistenten festgelegt und die Migration initiiert wurde, führt Disaster Recovery alle 30 Minuten eine Überprüfung durch, ob die Migration gemäß dem Plan verläuft. Der Fortschritt kann auf der Seite „Job Monitor“ überwacht werden.


NOTE: Die Migration wird derzeit für Kubernetes-basierte Workloads nicht unterstützt.

.Bevor Sie beginnen
Bevor die Migration gestartet wird, sollte ein Replikationsplan erstellt und für die Migration konfiguriert werden. Danach erscheint die Option *Migrieren* im Menü „Aktionen“.

.Schritte
. Melden Sie sich an bei https://console.netapp.com/["NetApp Console"^] .
. Wählen Sie in der linken Navigation der NetApp Console *Schutz* > *Notfallwiederherstellung*.
. Wählen Sie im Menü *Replikationspläne* aus.
. Wählen Sie den Replikationsplan aus.
. Wählen Sie rechts die Option *Aktionen* aus image:../use/icon-horizontal-dots.png["Symbol für das Aktionsmenü im NetApp Disaster Recovery -Dienst"], bewegen Sie den Mauszeiger über *Wiederherstellen* und wählen Sie dann *Migrieren* aus.
. Im Dialogfeld können Sie *Jetzt einen Snapshot erstellen* wählen, um einen neuen Snapshot für die Migration zu erstellen, oder *Auswählen*, um einen vorhandenen Snapshot für die Migration auszuwählen.
. Geben Sie "Migrate" in das Textfeld ein, um den Vorgang zu bestätigen, und wählen Sie dann *Migrate* aus.
