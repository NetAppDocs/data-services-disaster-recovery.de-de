= Zugriff auf NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
Für die Anmeldung bei NetApp Disaster Recovery werden Ihre Zugangsdaten für die NetApp Support Site verwendet, oder es erfolgt eine Registrierung für einen NetApp cloud login mit Ihrer E-Mail-Adresse und Ihrem Passwort https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["Erfahren Sie mehr über die Anmeldung"^].



[[user-roles]]
== Benutzerrollen

In NetApp Disaster Recovery erfordern bestimmte Aufgaben bestimmte Benutzerrollen. Es ist sicherzustellen, dass den Benutzern die richtigen Rollen zugewiesen wurden.

Weitere Informationen finden Sie unter: * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Benutzerrollen und Berechtigungen in NetApp Disaster Recovery"] * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["NetApp Console-Zugriffsrollen für alle Dienste"^]



[[log-into-disaster-recovery]]
== Anmeldung bei Disaster Recovery

. Öffnen Sie einen Webbrowser. Navigieren Sie zum  https://console.netapp.com/["NetApp Console"^].
. Melden Sie sich bei der NetApp Console an.
. Wählen Sie in der linken Navigation der NetApp Console *Schutz* > *Notfallwiederherstellung*.
+
Wenn Sie sich zum ersten Mal bei diesem Dienst anmelden, wird die Zielseite angezeigt und Sie können sich für eine kostenlose Testversion anmelden.

+
image:draas-landing6-free-trial.png["Screenshot der Landingpage für Disaster Recovery"]

+
Andernfalls wird das Disaster Recovery Dashboard angezeigt.

+
** Falls Sie noch keinen NetApp Console Agent hinzugefügt haben, fügen Sie einen hinzu. Weitere Informationen finden Sie unter  https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["Erfahren Sie mehr über Konsolenagenten"^].
** Wenn Sie ein Console Benutzer mit einem vorhandenen Agenten sind, wird beim Auswählen von *Disaster recovery* eine Meldung zur Registrierung angezeigt.
** Wenn Sie den Dienst bereits verwenden und „Notfallwiederherstellung“ auswählen, wird das Dashboard angezeigt.
+
image:dr-dashboard.png["Dashboard für Disaster Recovery"]
