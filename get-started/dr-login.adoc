= Zugriff auf NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
Melden Sie sich bei NetApp Disaster Recovery über die NetApp Console an.

Zum Anmelden verwenden Sie Ihre NetApp Support Site-Zugangsdaten oder melden Sie sich mit Ihrer E-Mail-Adresse und Ihrem Passwort für einen NetApp Cloud-Login an https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["Erfahren Sie mehr über die Anmeldung"^].

Bestimmte Aufgaben erfordern bestimmte Benutzerrollen. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Erfahren Sie mehr über Benutzerrollen und Berechtigungen in NetApp Disaster Recovery"]. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

.Schritte
. Öffnen Sie einen Webbrowser und gehen Sie zu https://console.netapp.com/["NetApp Console"^] .
+
Die Anmeldeseite der NetApp Console wird angezeigt.

. Melden Sie sich bei der NetApp Console an.
. Wählen Sie in der linken Navigation der NetApp Console *Schutz* > *Notfallwiederherstellung*.
+
Wenn Sie sich zum ersten Mal bei diesem Dienst anmelden, wird die Zielseite angezeigt und Sie können sich für eine kostenlose Testversion anmelden.

+
image:draas-landing6-free-trial.png["Screenshot der Zielseite für NetApp Disaster Recovery"]

+
Andernfalls wird das NetApp Disaster Recovery Dashboard angezeigt.

+
** Falls Sie noch keinen NetApp Console Agent hinzugefügt haben, fügen Sie einen hinzu. Weitere Informationen finden Sie unter  https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["Erfahren Sie mehr über Konsolenagenten"^].
** Wenn Sie ein NetApp Console-Benutzer mit einem bestehenden Agenten sind, erscheint beim Auswählen von *Disaster recovery* eine Meldung zur Registrierung.
** Wenn Sie den Dienst bereits verwenden und „Notfallwiederherstellung“ auswählen, wird das Dashboard angezeigt.


+
image:dr-dashboard.png["NetApp Disaster Recovery Dashboard"]
