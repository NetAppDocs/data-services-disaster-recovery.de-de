= Einrichten der Lizenzierung für NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
NetApp Disaster Recovery bietet verschiedene Lizenzoptionen, darunter eine kostenlose Testversion, ein Pay-as-you-go-Abonnement und Bring Your Own License (BYOL). Die Bestätigung des Lizenzmodells vor der Konfiguration von Disaster Recovery stellt sicher, dass der Dienst den Anforderungen Ihrer Organisation entspricht.

*Erforderliche NetApp Console-Rolle* Für die Ausführung dieser Aufgabe ist die Rolle „Superadministrator“, „Administrator für Notfallwiederherstellung“ oder „Anwendungsadministrator für Notfallwiederherstellung“ erforderlich. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Erfahren Sie mehr über Benutzerrollen und Berechtigungen in NetApp Disaster Recovery"^]. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].



[[licensing-options]]
== Lizenzierungsoptionen

Sie können die folgenden Lizenzierungsoptionen nutzen:

* Melden Sie sich für eine 30-tägige kostenlose Testversion an.
* Erwerben Sie ein Pay-as-you-go-Abonnement (PAYGO) für den Amazon Web Services (AWS) Marketplace oder den Microsoft Azure Marketplace.
* Bringen Sie Ihre eigene Lizenz (BYOL) mit. Dabei handelt es sich um eine NetApp Lizenzdatei (NLF), die Sie von Ihrem NetApp Vertriebsmitarbeiter erhalten. Sie können die Seriennummer der Lizenz verwenden, um BYOL in der NetApp Console zu aktivieren.



NOTE: Die Gebühren für Disaster Recovery basieren auf der genutzten Kapazität am Quellstandort, wenn mindestens eine VM oder Kubernetes-Ressource über einen Replikationsplan verfügt. Die Kapazität für einen Datastore nach einem Failover ist nicht im Kapazitätskontingent enthalten. Bei einem BYOL sind die Vorgänge im Service eingeschränkt, wenn die Daten die zulässige Kapazität überschreiten, bis Sie eine zusätzliche Kapazitätslizenz erwerben oder die Lizenz in der NetApp Console aktualisieren.

link:https://docs.netapp.com/us-en/console-licenses-subscriptions/concept-licenses-subscriptions.html["Mehr über Abonnements erfahren"^].

Nach Ablauf der kostenlosen Testversion oder der Lizenz können Sie im Dienst weiterhin Folgendes tun:

* Zeigen Sie beliebige Ressourcen an, beispielsweise eine Arbeitslast oder einen Replikationsplan.
* Löschen Sie beliebige Ressourcen, beispielsweise eine Arbeitslast oder einen Replikationsplan.
* Führen Sie alle geplanten Vorgänge aus, die während der Testphase oder unter der Lizenz erstellt wurden.




[[try-it-out-using-a-30-day-free-trial]]
== Probieren Sie es mit einer 30-tägigen kostenlosen Testversion aus

Sie können Disaster Recovery mit einer 30-tägigen kostenlosen Testversion ausprobieren.


NOTE: Während der Testphase gelten keine Kapazitätsbeschränkungen.

Um nach der Testphase fortzufahren, müssen Sie eine BYOL-Lizenz oder ein PAYGO-AWS-Abonnement erwerben.  Sie können jederzeit eine Lizenz erwerben und es entstehen Ihnen erst nach Ablauf der Testphase Kosten.

Während der Testphase steht Ihnen die volle Funktionalität zur Verfügung.

.Schritte
. Melden Sie sich an bei https://console.netapp.com/["NetApp Console"^] .
. Wählen Sie in der linken Navigation der NetApp Console *Schutz* > *Notfallwiederherstellung*.
+
Wenn Sie sich zum ersten Mal bei diesem Dienst anmelden, wird die Zielseite angezeigt.

+
image:draas-landing6-free-trial.png["Screenshot der Landingpage für Disaster Recovery"]

. Wenn Sie noch keinen Konsolenagenten für andere Dienste hinzugefügt haben, fügen Sie einen hinzu.
+
Informationen zum Hinzufügen eines Konsolenagenten finden Sie unter https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["Erfahren Sie mehr über Konsolenagenten"^] Die

. Nachdem Sie den Agenten eingerichtet haben, ändert sich auf der Landing Page von Disaster Recovery die Schaltfläche zum Hinzufügen des Agenten zu einer Schaltfläche zum Starten einer kostenlosen Testversion. Dazu wird *Start free trial* ausgewählt.
. Beginnen Sie mit dem Hinzufügen von primären Standorten und Standorten für die Notfallwiederherstellung.
+
Weitere Informationen finden Sie unter link:../use/sites-add.html["Sites hinzufügen"].





[[after-the-trial-ends-subscribe-through-one-of-the-marketplaces]]
== Nach Ablauf der Testphase abonnieren Sie über einen der Marketplaces

Nach Ablauf der kostenlosen Testversion können Sie entweder eine Lizenz von NetApp erwerben oder ein Abonnement über AWS Marketplace oder Microsoft Azure Marketplace abschließen. Dieses Verfahren bietet einen allgemeinen Überblick darüber, wie Sie sich direkt bei einem der Marktplätze anmelden können.

.Schritte
. In Disaster Recovery wird die Meldung angezeigt, dass die kostenlose Testversion abläuft. In der Meldung erfolgt die Auswahl von *Subscribe or purchase a license*.
+
Oder im Menü „Notfallwiederherstellung“ die Option „Zahlungsmethoden anzeigen“ auswählen.

+
image:dr-licensing-payment-methods.png["Seite „Zahlungsmethoden für Disaster Recovery“"]

. Wählen Sie *Im AWS Marketplace abonnieren* oder *Im Azure Marketplace abonnieren*.
. Das Abonnement für *Disaster Recovery* ist über AWS Marketplace oder Microsoft Azure Marketplace verfügbar.
. Wenn Sie zu Disaster Recovery zurückkehren, erhalten Sie eine Meldung, dass Sie abonniert sind.
+
Sie können Abonnementdetails auf der Abonnementseite der NetApp Console anzeigen. link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-homepage.html["Erfahren Sie mehr über die Verwaltung von Abonnements mit der NetApp Console"^].





[[after-the-trial-ends-purchase-a-byol-license-through-netapp]]
== Nach Ablauf der Testphase können Sie über NetApp eine BYOL-Lizenz erwerben.

Nach Ablauf der Testphase können Sie über Ihren NetApp Vertriebsmitarbeiter eine Lizenz erwerben.

Wenn Sie Ihre eigene Lizenz mitbringen (BYOL), umfasst die Einrichtung den Kauf der Lizenz, das Abrufen der NetApp -Lizenzdatei (NLF) und das Hinzufügen der Lizenz zur NetApp Console.



[[add-the-license-to-the-netapp-console]]
=== Die Lizenz zur NetApp Console hinzufügen

Nachdem Sie Ihre Disaster Recovery Lizenz von einem NetApp Vertriebsmitarbeiter erworben haben, können Sie die Lizenz in der Console managen.

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["Erfahren Sie mehr über das Hinzufügen von Lizenzen mit der NetApp Console"^].



[[update-your-license-when-it-expires]]
== Aktualisieren Sie Ihre Lizenz, wenn sie abläuft

Wenn sich Ihre Lizenzlaufzeit dem Ablaufdatum nähert oder Ihre lizenzierte Kapazität das Limit erreicht, werden Sie in der Disaster Recovery UI benachrichtigt. Sie können Ihre Disaster Recovery Lizenz vor ihrem Ablauf aktualisieren, damit Sie den Service ohne Unterbrechung nutzen können.


TIP: Diese Meldung erscheint auch in der NetApp Console und in https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#monitoring-operations-status-using-the-notification-center["Benachrichtigungen"] Die

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["Erfahren Sie mehr über die Aktualisierung von Lizenzen mit der NetApp Console"^].



[[end-the-free-trial]]
== Kostenlose Testversion beenden

Sie können die kostenlose Testversion jederzeit beenden oder warten, bis sie abläuft.

.Schritte
. In Disaster Recovery wird *Free trial - View details* ausgewählt.
. Wählen Sie in den Dropdown-Details *Kostenlose Testversion beenden* aus.
+
image:draas-trial-end3.png["Seite „Kostenlose Testversion beenden“"]

. Wenn Sie alle Daten löschen möchten, aktivieren Sie *Daten sofort nach Beendigung meiner kostenlosen Testversion löschen*.
+
Dadurch werden alle Zeitpläne, Replikationspläne, Ressourcengruppen, vCenters, Kubernetes-Cluster und Standorte gelöscht. Auditdaten, Betriebsprotokolle und der Auftragsverlauf bleiben bis zum Ende des Produktlebenszyklus erhalten.

+

NOTE: Wenn Sie die kostenlose Testphase beenden, keine Löschung Ihrer Daten beantragen und keine Lizenz oder kein Abonnement erwerben, löscht Disaster Recovery alle Ihre Daten 60 Tage nach Ablauf der kostenlosen Testphase.

. Geben Sie „Testversion beenden“ in das Textfeld ein.
. Wählen Sie *Ende*.
