:hardbreaks:
:allow-uri-read: 
:icons: font

[role="lead"]
Informationen zur Konfiguration von NetApp Disaster Recovery, damit Ihr System die Anforderungen für die erfolgreiche Erkennung von Workloads erfüllt und Replikationspläne zur Vorbereitung auf ein Failover konfiguriert werden können.

[role="quick-margin-para"]
