= Hinzufügen von lokalen und Amazon EVS vCenter-Clustern in NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Nachdem Sie Standorte erstellt haben, fügen Sie die vCenter-Cluster für jeden Standort in NetApp Disaster Recovery hinzu. Der Standorttyp bestimmt den Zugriff, den NetApp Disaster Recovery für die vCenters in diesem Standort benötigt. Amazon EVS vCenters und lokale vCenters verwenden dieselben Verbindungs- und Authentifizierungsinformationen.

.Schritte zum Hinzufügen eines vCenters zu jeder Site
. Wählen Sie unter der Option *Sites* für die gewünschte Site die Option *vCenter hinzufügen* aus.
+
image:evs-add-vcenter-1.png["vCenter-Option hinzufügen"]

. Wählen Sie im Dialogfeld „vCenter-Server hinzufügen“ die folgenden Informationen aus bzw. geben Sie sie ein:
+
.. Der NetApp Console , der in Ihrem AWS VPC gehostet wird.
.. Die IP-Adresse oder der FQDN für das hinzuzufügende vCenter.
.. Falls erforderlich, den Port auf den TCP-Port ändern, der von Ihrem vCenter Server verwendet wird.
.. Der vCenter-Benutzername für das zuvor erstellte Konto, der von NetApp Disaster Recovery zum Verwalten des vCenter verwendet wird.




. Wenn Ihre Organisation eine externe Zertifizierungsstelle (CA) oder den vCenter Endpoint Certificate Store verwendet, das Häkchen bei *Selbstsignierte Zertifikate verwenden* entfernen. Andernfalls das Kontrollkästchen aktiviert lassen.
+
.. Wählen Sie *Hinzufügen*.
+
image:evs-add-vcenter-2-3.png["Dialogfeld „vCenter hinzufügen“"]
